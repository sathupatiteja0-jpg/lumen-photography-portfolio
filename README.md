# LUMEN — Photography Portfolio

**Group 1 · Question 7: Photography Portfolio**

A responsive portfolio website for a fictional independent photography studio. The visual direction uses warm editorial colors, large photography, serif typography and generous spacing.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layouts
- `script.js` — mobile navigation and gallery category filters

## Features
- Responsive navigation for mobile and desktop
- Hero section and studio introduction
- Six-image portfolio gallery
- Working All / Nature / Architecture / People filters
- Services and contact sections

## Run locally
Open `index.html` in a browser. Internet access is needed for the Google Fonts and Unsplash images.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `lumen-photography`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the published website link to appear in the Pages section.

## Customize
Replace the demo contact address `hello@example.com` with a contact address you are comfortable publishing. Replace the Unsplash image URLs with your own licensed images if desired.
